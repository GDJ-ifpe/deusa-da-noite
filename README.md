# Eclipse – O Segredo da Deusa da Noite

## Desenvolvimento colaborativo

As tarefas de desenvolvimento serão organizadas por meio de issues e acompanhadas no GitHub Projects. Cada alteração deverá ser desenvolvida em uma branch própria e integrada por meio de pull request.

Para reduzir conflitos durante o desenvolvimento:

1. Cada puzzle deve possuir sua própria cena.
2. Cada personagem deve possuir sua própria cena.
3. `main.tscn` deve permanecer pequena e apenas conectar as partes principais.
4. Apenas um desenvolvedor deve modificar determinada cena durante uma issue.
5. Alterações em `project.godot`, `main.tscn` e nos scripts de `autoload/` devem ser combinadas previamente entre os desenvolvedores.
6. As cenas devem se comunicar preferencialmente por sinais, evitando referências rígidas entre sistemas.
7. Cada pull request deve tratar de uma funcionalidade delimitada.
